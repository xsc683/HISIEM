# Story 文档迁移说明

原来的 10 份 Story 详文采用同一套长模板，重复维护 API、路由、状态和设计决策；其中部分内容已经落后于当前代码，容易误导开发和 AI 编码助手。它们已在文档整理中删除，不再作为接口或功能状态来源。

当前唯一的产品/验收入口是：[当前产品契约](../product-contract.md)。其中保留了：

- 当前前端真实路由和菜单；
- 按模块归类的 API 契约；
- 数据源 → 事件 → 规则 → 告警 → 案件 → 通知的主旅程；
- 稳定 ID、时间语义、权限和错误处理约束；
- 面向回归测试的验收清单。

需求变化时，先更新产品契约和代码测试；不要重新创建一份复制 API 的 Story 长文。需要记录阶段计划时更新 [`../roadmap.md`](../roadmap.md)，需要记录架构决策时更新 [`../design-decisions.md`](../design-decisions.md)。
